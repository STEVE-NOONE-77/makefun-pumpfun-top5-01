Forecasts the five largest new pump.fun coins at each answer read, 7 to 13 hours after its history ends, with a Monte Carlo of the whole field: the coins in the history (most collapse, the steady ones hold) and the coins still to be launched. Each place gets a probability for each named coin and a probability for each market-cap size bin.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
